# Tipos de Datos Abstractos (TDAs)

## Estructuras Implementadas

### [Lista Enlazada (`lista`)](./lista)
> Lista simplemente enlazada. 
> Permite almacenar elementos de tipo genérico, insertar y borrar al principio o final, e iterar sobre sus elementos (con iteradores internos y externos).

### [Pila (`pila`)](./pila)
> Pila (Stack) 
> Soporta operaciones básicas como apilar, desapilar y ver el tope.

### [Cola (`cola`)](./cola)
> Cola (Queue)
> Soporta operaciones básicas como encolar, desencolar y ver el primero.

### [Cola de Prioridad (`heap`)](./heap)
> Cola de Prioridad (Priority Queue)
> Permite manejar elementos ordenados según un criterio de comparación, ofreciendo acceso eficiente al máximo (o mínimo).

### [Árbol Binario de Búsqueda (`abb`)](./abb)
> Árbol Binario de Búsqueda (BST)
> Permite inserción, búsqueda y borrado de elementos en tiempo logarítmico promedio.

### [Tabla de Hash (`hash`)](./hash)
> Tabla de Hash (Hash Table)
> Permite operaciones de guardar, buscar y borrar en tiempo constante promedio.
